# Writing supplement: economics

Read the general rules in [AGENTS.md](../../AGENTS.md) first. This file only covers what economics does differently or more specifically.

## Core block order: assumptions → derivation → worked numbers → curve shifts → policy → model limitation

Open with an examinable statement as usual (for example, "if planned investment is fixed, equilibrium total saving does not change"), then follow this order. A section does not need all six steps, but a section that teaches a model has at least assumptions, derivation and model limitation.

1. **Assumptions**: the model's premises exactly as the slides list them (closed or open economy, fixed prices or not, constant MPC, which variables are exogenous). Every later step should point back to an assumption.
2. **Derivation**: from the definitions or behavioural equations to the equilibrium condition or multiplier, saying which assumption each step uses. Keep `≡` (an accounting identity, true by definition) apart from `=` (an equilibrium condition, true only in equilibrium); never write an identity as a cause.
3. **Worked numbers**: use the slides' numbers first. Numbers you make up are labelled "made-up numbers, not from the slides" and can be worked through step by step; show the working, not only the result.
4. **Curve shifts**: which curve moves, in which direction, because which variable changed; tell a shift of the curve apart from a movement along it. Read only the scaled parts of a figure; a shift distance the original figure does not give is not read.
5. **Policy**: which instrument, which direction, and the expected result under these assumptions. A policy conclusion is always conditional on the model's assumptions.
6. **Model limitation (one)**: which assumption matters most and how the conclusion changes when it is relaxed; the lecturer's own reservations go here. Comparative statics are not written as "the economy jumps to the new equilibrium straight away".

## Notation and formulas

- Use the slides' symbols (for example Iᵖ, C̄, Y*). Write maths in Unicode with `<sup>` and `<sub>`; the page has no LaTeX renderer, and the validator rejects raw LaTeX.
- One equation per line in a derivation, using separate `<p>`s when needed; do not squeeze several steps into one line.

## Question types (in your coverage notes, never in the stem)

| Type | Tests |
|---|---|
| Discrimination | identity vs equilibrium, stock vs flow, nominal vs real, shift vs movement along |
| Derivation | one step from the assumptions to the conclusion |
| Calculation | equilibrium, multiplier, value added and similar from numbers |
| Graph | which curve moves, its direction, where the new equilibrium is |
| Policy | an instrument's direction and its result |
| Limitation | whether the conclusion survives relaxing an assumption |

- Definition questions are at most 30%.
- Distractors in calculation questions come from typical mistakes (counting intermediate goods twice, the wrong c in the multiplier, forgetting the tax rate or import propensity), not from arbitrary numbers.
- In wording questions, the correct option is not the only "most carefully hedged" one; distractors give reasons too and are as long.

## Discipline lines

- An accounting identity is not written as a cause, nor as an equilibrium.
- Numbers the slides do not give are not filled in; made-up numbers are labelled.
- No values read off a figure with no scale.
